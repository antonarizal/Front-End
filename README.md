# Front-End Learning Repository

Repository ini berisi kumpulan latihan dan materi belajar dasar hingga lanjutan mengenai pengembangan front-end, terutama menggunakan HTML, CSS, dan JavaScript.

## Deskripsi

Project ini dibuat sebagai tempat untuk:
- mempraktikkan struktur HTML
- belajar styling dengan CSS
- memahami interaksi dan logika JavaScript
- mencoba berbagai konsep front-end secara mandiri

## Struktur Folder

- `HTML/` : berisi file latihan dan materi terkait HTML
- `CSS/` : berisi file latihan untuk styling, layout, animation, responsive design, dan konsep CSS lainnya
- `JS/` : berisi file latihan JavaScript, DOM, event handling, async, storage, dan berbagai fitur JS
- `Audio/` : berisi file audio pendukung latihan
- `Image/` : berisi aset gambar yang digunakan dalam proyek

## Teknologi yang Digunakan

- HTML
- CSS
- JavaScript

## Cara Menjalankan

1. Clone atau unduh repository ini.
2. Buka folder project di browser.
3. Buka file `.html` yang ingin dipelajari atau dijalankan.
4. Untuk latihan JavaScript, Anda juga bisa membuka file `.js` melalui browser console atau menjalankannya dengan Node.js jika diperlukan.

## Tujuan Project

Project ini bertujuan untuk membantu proses belajar front-end secara praktis dengan contoh-contoh yang mudah dipahami dan dapat dikembangkan lebih lanjut.

## Catatan

Repository ini bersifat edukatif dan cocok digunakan untuk latihan mandiri, pembelajaran, maupun referensi dasar dalam pengembangan web.

## Lisensi

Project ini dibuat untuk tujuan pembelajaran. Silakan gunakan secara bijak dan sesuaikan kebutuhan Anda.
